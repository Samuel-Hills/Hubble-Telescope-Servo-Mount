# Reference inputs

| File | Use | Notes |
|---|---|---|
| `Feetech_STS3215-C044_Datasheet.pdf` | Supplied C044 dimensional/electrical source | Use the specific C044 sheet for servo dimensions and ratings. |
| `ST3215.step` | Simplified/derived servo reference solid | The source solid has invalid geometry in places; it is retained for comparison. The assembly uses a clean parametric envelope instead. |
| `ST3215-3D.zip` | Supplied servo 3D-model archive | Original input archive retained. |

The supplied LEGO set 11382 instruction PDF is not included. It is a large,
copyrighted assembly guide rather than dimensioned CAD, and this project does
not derive any precise dimensions from its perspective illustrations. The
reported LEGO-side cross-feature geometry remains a physical measurement task.
