# Archived passive sleeve variants

These STEP/STL files are retained from earlier bearing-based iterations:

- `tilt_passive_sleeve` — round-bore sleeve.
- `tilt_passive_cross_sleeve` — cross-socket journal sized to run inside an 8 mm
  bearing bore.

Neither is used by the current assembly. The current passive-side part is
`../tilt_passive_printed_pivot`, which fits directly in the yoke's nominal
22 mm bore. Keep archived parts separate when slicing to avoid choosing an
obsolete version.
